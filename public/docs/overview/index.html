入门

产品概览

乡村经营的决定，常常要同时看政策、资源、产业、资金和风险。材料多，口径要统一，时间又紧。

WAI 乡村经营智能体帮助乡镇和村集体的工作人员做这类案头工作。它读取你提供的资料，查证现行政策，分方面分析，并写成可以直接修改的文稿。每个结论都能展开过程和来源，方便你核对后用于正式材料。

#开始使用

快速开始登录、选择 Chat 或 Work、写问题、查看回答。 登录与界面登录系统，认识左侧栏、对话区和会话详情。 两种工作方式Chat 与 Work 的区别和选择。

#主要概念

概念含义
助手你在对话窗口里交流的对象。页面里称为「WAI 智能体」，本文档称为「助手」
工作方式新建对话时选择：Chat 或 Work。决定助手是否组织专家、结果以什么形式交付
过程区回答上方的折叠区域，显示助手的思考和工具调用。见回答的组成
会话详情对话右侧的面板，集中显示本轮的输出文件、任务、专家和来源。见会话详情
专家Work 中负责某个领域的分析者，共八类。见Work
技能预先写好的一套工作方法，可为一条消息选用，共 12 项。见技能
知识库管理员整理的政策、案例、经验材料，所有账号可用。见知识库
分支从一条消息出发创建的新对话，原对话保持不变。见历史、重试与分支

#适用场景

政策理解解读文件，梳理适用条件、申报路径和合规要求，列出来源。 工作研究上传调研材料和台账，比较、归纳，分析原因，形成综合判断。 方案设计从资源、产业、财务、风险等方面同时论证一个项目。 规划编制起草规划讨论稿等长文件，在页面预览，导出 PDF 或 Word。 材料起草起草、改写汇报材料、调研报告和工作方案，保留你的事实和口径。 日常咨询回答一般问题，改写润色，对着文件提问。

#功能

输入框与发送模型、思考强度、联网搜索、知识库。 回答的组成过程区、正文、参考来源和操作行。 会话详情集中查看本轮的文件、任务、专家和来源。 知识库政策、案例、经验三类公共资料。 历史、重试与分支重新生成，编辑重发，创建分支，比较不同回答。 设置外观、个人资料、个性化、用量。

#管理员与支持

版本记录版本记录以仓库 tag 为准，页面只列当前产品事实。 账号与用量管理创建账号，重置密码，查看用量。 维护知识库上传文件，导入链接，启用或停用条目。 常见问题按现象查原因和处理办法。
