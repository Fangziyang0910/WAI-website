两种工作方式

Chat

日常的案头问题，不需要多位专家分头分析：核对一个条款，改一段汇报材料，对着一份台账算几个数。Chat 适合这类问题，等待时间最短。

#工作方式

Chat 里只有一个助手。你发送问题后，它直接思考并回答。它不会把任务交给专家，也不建立工作区、不生成文件。

需要时，它会使用这些工具：

  • 读取你上传的文件。 见上传图片和文件。
  • 联网搜索。 在输入框开启「智能搜索」后可用。见联网搜索。
  • 读取知识库。 在输入框开启「知识库」后可用。见知识库。
  • 做计算。 算式、预算、现金流，由计算工具核算。

Chat 默认使用当前模型的中档思考强度（DeepSeek high、Qwen medium）。如果问题简单，可以在输入框把思考强度调到 low 或 off；如果问题需要更多推理，可以调到 max（DeepSeek）或 xhigh（Qwen），见输入框与发送。

#适用场景

#问一个具体的问题

什么是「三变」改革？它适合我们这种没有集体收入的村吗？

#对着文件提问

先上传文件，再问：

附件是我们村去年的收支表。请算出全年总收入和总支出，并指出哪三项支出占比最大。
附件是一份政策文件。请列出申报条件，每条标明原文在第几页。

#改写和润色

请把下面这段话改写成适合在村民大会上宣讲的口语，不超过 200 字：……

#联网查一个事实

开启「智能搜索」，再问：

兴业县 2026 年有哪些农产品加工扶持政策？请列出政策名称、发布单位和来源链接。

#使用技巧

  • 一次问一件事。 问题太多，回答容易遗漏。拆成几次追问，更清楚。
  • 给出材料。 助手只知道你告诉它的和你上传的，不知道你们村的具体情况。
  • 追问。 同一段对话里，助手记得前面的内容。「把第二点展开」「换成表格」都可以直接说。

需要从几个方面同时判断，或者要一份能下载的报告时，新建一段对话，改用 Work。

#相关

Chat 与 WorkChat 与 Work 是两种工作方式，共用一个输入框；区别在于是否组织专家、是否保存和交付文件。上传图片和文件把文件和图片发给助手，让它对着材料回答。联网搜索开启「智能搜索」后，助手可以上网查政策、行情和新闻，并列出来源。
