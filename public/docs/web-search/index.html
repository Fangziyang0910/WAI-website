联网搜索

政策和行情会变化。写进正式材料之前，应当以现行有效的文件为准。开启联网搜索后，助手列出每次检索的关键词和来源，你可以逐条打开原文核对。

#适用场景

助手自己掌握的知识有截止日期，也不了解你们当地的最新通知。这些情况需要联网：

  • 查现行有效的政策，如扶持政策、申报通知。
  • 查最新的行情和动态，如农产品价格、市场新闻。
  • 查当地的公开信息，如政府网站上的公告。

只需要对着你上传的文件回答，或者回答一般性的知识问题，不用联网。

#开启联网搜索

「智能搜索」在输入框下方一排按钮的右侧，地球图标。点一下开启，按钮变成高亮；再点一下关闭。

开启后，发送问题。助手自己判断要不要搜、搜什么、读哪些网页。

Chat 与 Work 都能使用联网搜索。

  • 已读取网页：域名 是助手打开阅读了的网站。
  • 两次工具调用之间的说明文字，讲了助手刚发现了什么、接下来做什么。

#提问方法

联网搜索的问题，要写清地区、时间和主体。

要写的为什么例子
地区政策分级别，不同县、市的政策不同「广西兴业县」比「广西」好
时间避免找到已过期的旧政策「2026 年仍有效的」
主体政策对象不同，申报条件不同「农民专业合作社」「村集体」
要的格式方便你核对「按政策名称、发布单位、适用对象列成表，附来源链接」

示例：

广西兴业县、玉林市现在有哪些支持农产品加工和乡村特色产业的扶持政策？请按政策名称、发布单位、适用对象列成表，并给出来源链接。
查一下近三个月玉林地区肉鸡的收购价走势，并说明数据来自哪个网站、哪一天。

#核对来源

助手整理的是网页上的信息。涉及钱、资格和期限的内容，请打开来源核对原文。

一个真实的例子：用上面第一条问题搜索，助手在回答开头说明了一个容易混淆的地方：

网络检索中出现的“农业全产业链开发项目”“牛腩粉奖补”“乡村特色产业新质生产力项目”等文件，多数是玉州区（玉林市辖区）印发的，不能直接适用于兴业县。

接着，它按「国家或自治区、玉林市、兴业县」三个层级分别列出政策，并标明哪些是现行可申报，哪些已到期需要确认续期。

这个例子说明核对时要看的几件事：

  1. 发布单位。 是哪一级政府、哪个部门。
  2. 适用地区。 是你们那个县吗，还是邻近地区。
  3. 发布日期和有效期。 政策可能已经到期。
  4. 适用对象。 个人、合作社、企业，申报条件各不相同。
  5. 原文条款。 补贴比例、金额、材料清单，以原文为准。

#搜索不到，或者结果不对

  • 换关键词再问。 把问题说得更具体，或者换一种说法。
  • 缩小范围。 把「各种政策」改成「农产品加工设备购置补贴」。
  • 自己提供原文。 找到政策文件后，作为附件上传，让助手对着原文回答。这比让助手搜索更准，见上传图片和文件。
  • 把可靠的材料交给管理员放进知识库。 以后所有人都能直接使用，见知识库。

#相关

知识库编写材料时，常要参照上级政策、其他地区的做法和成熟经验。知识库把这三类资料预先整理在产品里，提问时让助手先查阅，回答会标明出处。回答的组成一条回答由过程区、正文、参考来源和操作行四部分组成。上传图片和文件把文件和图片发给助手，让它对着材料回答。
