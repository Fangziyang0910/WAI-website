两种工作方式

Chat 与 Work

查一个政策条款、改写一段材料，和论证一个项目、编制一份规划，需要的分析方式和交付形式不同。工作方式决定这些差别。

#两种方式的区别

ChatWork
谁来回答一个助手主顾问；按需请相关领域的专家
工作方式直接回答，需要时检索资料、做计算先理解任务，把专业部分交给专家，再取舍、统稿
有没有工作区没有；对话里直接给答案有；可以在会话工作区里创建、保存文件
结果在哪对话里的一段回答对话里的回答，或右侧「输出」里的文件；可预览、下载、导出
页面上的说明日常问答、文字改写和简短讨论。直接回答，按需检索资料和计算。持续分析和完善方案。可按需咨询专家、保存资料，并预览和导出文件。

两种方式都能上传文件、开启联网搜索、使用知识库，也都按每一轮调整模型和思考强度，见输入框与发送。

#如何选择

你想做的事选
问一个具体问题、查一个数字、改写一段话Chat
对着一份文件，问几个问题Chat
想知道一件事从资源、政策、财务、风险等不同角度看是什么结论Work
要比较几个方案，并得到有分工、有依据的判断Work
要一份能在页面预览、下载或导出的规划、方案、报告Work

不确定时，先用 Chat 问。回答不够用，或者需要专家分头分析、需要交付文件，再新建一段对话，选 Work。

#选好方式再提问

  1. 点左上角的「新对话」。
  2. 页面中央有 Chat 和 Work 两个标签，点你要的那一个。切换条下方一行文字会变成这种方式的说明。
  3. 写问题，发送。

方式在新建对话时选定。选定后，这段对话一直使用这种方式，对话页顶部的小标签会写明是哪一种。想换方式，新建一段对话。

两种方式的详细用法：

  • Chat
  • Work
