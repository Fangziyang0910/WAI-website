#当前产品事实

项目现行实现
工作方式只有 Chat 与 Work 两种，新建对话时选定，之后不能更改。见 Chat 与 Work
技能共 12 项，为单条消息选用。见技能
个性化只保存你自行编写的回答指令。产品不提供个人记忆，助手不读取也不保存跨对话的个人记忆

#变更说明

  • 工作方式收敛为 Chat 与 Work。 早期版本的工作方式划分已取消：Chat 处理日常问答与资料阅读，Work 增加文件编辑、专家协同与文件交付。模式在新建对话时选定且不能更改，需要另一套工具时新建对话。
  • 个性化只保留你写的指令。 早期版本的记忆功能已移除，回答指令保持不变。
  • 用量只做统计。 用量页显示 token 与联网调用，不限制使用额度。

#相关

产品概览WAI 乡村经营智能体是面向乡村经营工作的智能体，协助开展工作研究、政策理解、规划编制、方案设计和日常咨询。Chat 与 WorkChat 与 Work 是两种工作方式，共用一个输入框；区别在于是否组织专家、是否保存和交付文件。账户设置设置包括三项：常规、个性化、用量。账号与用量管理公司管理员管理本组织账号和用量；平台管理员开通组织并指定公司管理员。技能技能是预先写好的一套工作方法，告诉助手分析某类问题时该看什么、怎么做。历史、重试与分支管理历史对话，以及对一条消息重新回答、编辑重发和创建分支。
